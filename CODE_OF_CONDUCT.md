# Code of Conduct

## Our pledge

We want this repository to be a place where students can ask basic hardware
questions, disagree about control theory, and review each other's work without
harassment.

## Expected behavior

- Be specific and evidence-based; attach logs, photos, or test IDs.
- Critique the design, not the person.
- Respect competition rules and academic integrity.
- Do not publish another team's credentials, private data, or unpublished work.

## Unacceptable behavior

Harassment, personal attacks, discrimination, doxxing, or publishing secrets.

## Enforcement

Maintainers may edit or remove comments and may block contributors who violate
these rules. Report concerns privately to the maintainers listed in the
repository profile.
