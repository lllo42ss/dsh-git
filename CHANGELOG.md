# Changelog

All notable changes are documented here. Format follows Keep a Changelog.

## [1.0.0] - 2026-08-01

### Added

- GitHub Actions CI for Python tests and repository checks.
- Issue/PR templates and contribution guide.
- Release checklist and final design-report outline.

### Changed

- Promoted the control prototype to the submission baseline.
- Documented the sign convention for ball position and beam angle.

## [0.1.0] - 2026-08-01

### Added

- Requirements/scoring breakdown for the 2026 H-problem.
- ESP32-S3 firmware skeleton with cascaded PID.
- Ball-on-beam simulation and five-channel line-following helpers.
- OpenCV ball tracker prototype and serial protocol.
- BOM, pin map, architecture, control design, test plan and ADRs.
- Unit tests, repository self-check, and a small Git branch/merge history.
