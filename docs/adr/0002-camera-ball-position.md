# ADR 0002：球位置使用摄像头，循迹只用红外

- 状态：Accepted
- 日期：2026-08-01
- 决策者：视觉组/控制组

## 背景

题目要求球位置检测必须使用摄像头，同时循迹模块只能使用红外光电模块。两者不能混用。

## 决策

- 球位置：OV2640 俯视摆杆，ROI + 阈值/轮廓，像素坐标标定为厘米；
- 循迹：5 路红外阵列，只输出黑线偏差；
- 摄像头不参与循迹，避免违反题目限制；
- 图传与视觉共用摄像头，但控制只使用视觉结果，不依赖车外画面。

## 后果

优点：

- 满足题目强制约束；
- 视觉与循迹解耦，故障可分别降级；
- 图传画面和球位置使用同一来源，便于复盘。

代价：

- 摄像头延迟和光照敏感；
- 需要现场标定；
- 球与凹槽对比度不足时要补光/调阈值。
