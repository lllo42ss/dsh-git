# ADR 0001：采用串级 PID 而不是单环控制

- 状态：Accepted
- 日期：2026-08-01
- 决策者：控制组

## 背景

球在摆杆上是双积分器，单环位置 PID 容易振荡；舵机本身还有角度动态。直接把位置误差映射到舵机 PWM，响应慢且超调大。

## 决策

采用串级结构：

- 外环球位置 PID → 目标摆角；
- 内环摆角 PID → 舵机 PWM；
- 叠加小车加速度前馈。

## 后果

优点：

- 内环先稳定，外环整定更容易；
- 限幅、抗饱和可以分层处理；
- 便于单独测试舵机和视觉。

代价：

- 需要角度反馈或可靠的舵机模型；
- 参数更多，整定时间更长；
- 代码结构要求更清晰。

## 备选方案

- 单环位置 PID：实现简单，但抗扰和超调较差；
- MPC/LQR：理论更优，但比赛现场标定和算力成本高。
