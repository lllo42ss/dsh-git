# 测试计划

## 1. 测试环境

- 白色广告布 + 黑色环形线，线宽 1.8±0.2 cm；
- AB/CD 1.5 m，BC/DA 半圆 R=0.5 m；
- A 点启停线 5 cm，基准虚线 30 cm；
- 秒表/手机慢动作、直尺、电压表、电子秤；
- 车外图传接收端（笔记本 + 录像软件）。

## 2. 功能测试

| ID | 测试 | 步骤 | 通过标准 |
|---|---|---|---|
| F-01 | 上电自检 | 上电，观察 OLED | 显示版本、电压、传感器状态 |
| F-02 | 红外标定 | 黑线/白底分别读取 | 5 路阈值区分明显，无抖动 |
| F-03 | 舵机中位 | 复位，直尺测摆杆 | 水平误差 ≤0.5° |
| F-04 | 球位置视觉 | 球放 O/+5/-5 cm | 视觉读数误差 ≤0.3 cm |
| F-05 | 图传 | 车外接收 | 画面覆盖整杆，延迟可感知但不影响录像 |
| F-06 | 启动/停车 | 按键启动，A 点停车 | 计时启停正确，停车偏差 ≤2 cm |

## 3. 性能测试

| ID | 测试 | 通过标准 |
|---|---|---|
| P-01 | 静止 O→+5→-5 cm | ≤5 s，±5 cm 处误差 ≤1 cm |
| P-02 | A→B | ≤8 s，球在中心 ±1 cm |
| P-03 | 整圈（中心保持） | ≤30 s，球在中心 ±1 cm |
| P-04 | 整圈（任意点） | ≤30 s，球在指定点 ±1 cm |
| P-05 | 一圈竞速 | ≤20 s，停车 ≤2 cm |
| P-06 | 图传录像回放 | 完整记录每次测试，能看清球轨迹 |

## 5. 回归策略

- 每次修改控制参数，至少跑 P-01 + P-02；
- 每次修改循迹/电机，至少跑 P-03；
- 每次修改视觉，先跑 F-04，再跑 P-01；
- 提交前跑 `python -m unittest discover -s tests -v` 和 `python scripts/check_repo.py`。

## 6. 安全

- 调试时车轮架空；
- 舵机首次上电限制 PWM，防止机械撞限位；
- 电池不过放，单片低于 3.4 V 停止；
- 图传天线远离人体，避免长时间近距离辐射。
