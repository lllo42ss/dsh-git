# 需求拆解（2026 电赛 H 题）

> 来源：`H题_车载平衡滚球运动控制系统 (2).pdf`。以下为工程拆解，不替代命题原文；比赛时以赛区发布的正式题目为准。

## 1. 任务边界

设计一辆载有平衡滚球装置的循线小车：

- 小车沿黑色环形路线顺时针行驶；
- 行驶过程中，钢球在摆杆凹槽内保持稳定；
- 摆杆左端铰接，离小车平板高度 `h >= 5 cm`；
- 摆杆由角度控制机构驱动，可把球稳定在指定位置；
- 车载摄像头采集摆杆画面，图传发送到车外接收端，实时显示并完整录像、可回放。

## 2. 强制约束

| 约束 | 值 | 设计影响 |
|---|---|---|
| 车身尺寸 | 长 ≤35 cm，宽 ≤25 cm | 摆杆 25 cm、电池、驱动、图传都要压缩布置 |
| 循迹传感器 | 只能使用红外光电模块 | 不能用摄像头做循迹；摄像头只做球位置 |
| 显示 | ≤2 英寸，安装在方便观测处 | OLED 显示时间、状态、球位置 |
| 启动 | 必须有人工启动按键 | 按键触发计时和状态机 |
| 供电 | 车载电池 | 电机与舵机要分路稳压，避免复位 |
| 摆杆 | 4 分 PPR 管改造，内壁光滑，不得增摩擦 | 球位置控制只能靠角度，不能靠机械限位 |
| 球位置检测 | 必须使用摄像头 | 视觉坐标到厘米坐标要标定 |
| 图传 | 发送端在车上，接收端在环外 | Wi-Fi/图传模块 + 车外录像 |

## 3. 评分项与实现映射

| 评分项 | 分值 | 实现要点 | 验收方式 |
|---|---:|---|---|
| 图传显示与录像 | 6 | 车载 Wi-Fi JPEG 流，车外 VLC/浏览器接收并录屏 | 实时画面覆盖整根摆杆，回放能看清球轨迹 |
| 一圈 ≤20 s，停车 ≤2 cm | 16 | 红外循迹 PID + 编码器里程 + 启停线检测 | 秒表 + 停车基准线 |
| O→+5→-5 cm，≤5 s，误差 ≤1 cm | 13 | 球位置串级 PID + 摆杆角度环 | 摄像头标定 + 直尺复核 |
| A→B ≤8 s，球在中心 ±1 cm | 20 | 循迹前馈 + 球位置保持 | 分段计时 + 视频 |
| 整圈 ≤30 s，球在中心 ±1 cm | 20 | 全局速度规划 + 前馈补偿 | 整圈计时 + 视频 |
| 整圈 ≤30 s，球在任意点 ±1 cm | 20 | 可切换目标位置 + 自适应 PID | 指定点 + 视频 |

## 4. 关键风险

1. **球在坡上自由滚动，开环不可行**：必须有位置反馈，且采样延迟要小于 ~50 ms。
2. **摄像头延迟/丢帧**：视觉线程与运动控制解耦，控制周期内保持上一帧目标，超时降级为角度保持。
3. **小车加减速造成球前后窜动**：用纵向加速度前馈，而不是只靠 PID。
4. **红外循迹在圆弧段丢线**：5 路传感器 + 丢线记忆 + 降速搜索。
5. **电机/舵机电流冲击导致主控复位**：电机电源与逻辑电源分路，加 TVS/大电容。
6. **图传与 Wi-Fi 控制争抢带宽**：图传单独信道/端口，控制指令走串口或低带宽 UDP。

## 5. 比赛现场检查清单

- [ ] 车身长宽、摆杆高度、摆杆长度符合题目
- [ ] 5 路红外模块工作正常，黑线/白底阈值现场重标
- [ ] 摄像头画面覆盖 -6 cm 到 +6 cm，刻度清晰
- [ ] 图传接收端能录像，存储空间足够
- [ ] 启动按键、OLED、急停/断电方式可用
- [ ] 电池电压充足，舵机中位机械对中
- [ ] 所有参数可保存，断电后不丢
