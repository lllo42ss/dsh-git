# 循迹整定记录

## 目标

- 直道不蛇形；
- 半圆不切内圈；
- 丢线后能在 200 ms 内降速并找回。

## 方法

1. 先只给 P，找到开始蛇形的临界值；
2. 加 D 抑制超调，D 过大时会放大红外噪声；
3. 半圆段单独降速，速度规划优先于增大 PID；
4. 每次修改只动一个参数，记录测试圈速和最大偏差。

## 当前基线

| 参数 | 值 | 说明 |
|---|---:|---|
| 基础速度 | 0.55 | 归一化 PWM |
| Kp | 45 | 误差到转向 |
| Kd | 8 | 抑制蛇形 |
| 丢线超时 | 200 ms | 超时进 FAULT |

> 实车请从低速开始，逐步提高基础速度；不要直接套用表格。
