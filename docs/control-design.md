# 控制设计

## 1. 球-摆杆模型

设球质量 `m`、摆杆倾角 `θ`、球位置 `x`（中心 O 为 0，右正），忽略滚动摩擦时有：

```text
x'' = (5/7) * g * sin(θ)
```

小角度下 `sin(θ) ≈ θ`，传递函数近似为：

```text
X(s) / Θ(s) = (5g/7) / s²
```

这是一个**双积分器**，没有阻尼，必须闭环；仅用比例控制会持续振荡。

## 2. 串级控制

```text
x_target ──► [位置 PID] ──► θ_target ──► [角度 PID] ──► 舵机 ──► 摆杆 ──► 球
                  ▲                                      │
                  └──────────── 视觉 x_feedback ─────────┘
```

- 外环：球位置 PID，输出目标摆角，限幅 ±12°；
- 内环：舵机角度 PID，周期 5 ms；
- 前馈：`θ_ff = -(7/(5g)) * a_car`，抵消小车纵向加速度；
- 目标位置可切换：`O`、`+5 cm`、`-5 cm`、任意 `x`。

## 3. 离散 PID

```text
e[k] = target - measured
P    = Kp * e[k]
I    = I + Ki * e[k] * dt        (带条件积分/抗饱和)
D    = Kd * (e[k] - e[k-1]) / dt
u    = clamp(P + I + D, u_min, u_max)
```

工程细节：

- 微分项对测量值求导，避免目标突变产生微分冲击；
- 积分分离：`|e| > 3 cm` 时暂停积分；
- 输出限幅 + 积分回算抗饱和；
- 死区 ±0.15 cm，防止舵机抖动；
- 视觉丢失时保持上一有效目标，超时回中。

## 4. 循迹控制

5 路红外按位置加权：

```text
error = Σ(w_i * s_i) / Σ(s_i)
```

`w = [-2, -1, 0, 1, 2]`。PD 控制输出转向量，基础速度由路段决定：

- 直道：较高速度；
- 半圆：降速，增大 D；
- 丢线：按最后误差方向原地/低速搜索；
- 检测到 A 点启停线：刹车 + 里程补偿。

## 5. 前馈补偿

小车纵向加速度 `a` 使球受到惯性力。由模型：

```text
θ_ff = -(7/(5g)) * a
```

`a` 由编码器速度差分得到，低通滤波后叠加到球位置环输出。前馈不替代反馈，只降低反馈负担。

## 6. 参数整定顺序

1. 舵机中位、角度传感器线性度；
2. 内环角度 PID（空载，阶跃 5°）；
3. 外环球位置 PID（静止，O→+5 cm）；
4. 加前馈（小车匀速/加减速）；
5. 循迹 PID（直道→半圆→整圈）；
6. 联调：先低速整圈，再逐步提速到 30 s/20 s。
