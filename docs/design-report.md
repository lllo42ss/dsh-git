# 设计报告提纲

## 摘要

本作品为 2026 年电赛 H 题“车载平衡滚球运动控制系统”。小车使用 5 路红外循迹、ESP32-S3 主控、双电机差速驱动；摆杆由舵机驱动，OV2640 摄像头检测钢球位置，通过 Wi-Fi 图传到车外显示并录像。控制上采用球位置-摆角串级 PID，并叠加小车加速度前馈。测试表明……

## 1. 方案论证

- 主控方案比较：ESP32-S3 / STM32F411 + 独立图传 / K210；
- 循迹方案：红外阵列（题目强制）；
- 球位置方案：摄像头（题目强制）；
- 摆杆驱动：舵机 + 连杆 vs 步进 + 丝杆。

## 2. 理论分析
